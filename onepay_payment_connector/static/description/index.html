OnePay Payment Provider for Odoo 19

Accept secure online payments through OnePay in Sri Lanka

Connect Odoo 19 with the OnePay payment gateway and allow customers to complete online payments from the customer invoice portal and Odoo eCommerce checkout. The integration handles payment redirection, callback processing, transaction verification, and payment status updates inside Odoo.

Odoo 19 Invoice Portal eCommerce Multi-company

Key Features

Invoice Portal Payments

Customers can open an invoice from the Odoo portal and pay online using OnePay.

eCommerce Checkout

OnePay appears as an available payment method during Odoo website checkout.

Hosted Payment Page

Customers are redirected to the OnePay-hosted payment page to complete payment.

Webhook Verification

Incoming callbacks are processed and verified before the Odoo transaction is confirmed.

Automatic Status Update

Odoo payment transactions are automatically updated after successful verification.

Multi-company Ready

Configure separate OnePay providers and credentials for different Odoo companies.

Configuration

  1. Install the module in your Odoo 19 database.
  2. Go to Accounting > Configuration > Payment Providers.
  3. Open the OnePay payment provider.
  4. Enter the OnePay App ID, App Token, and Hash Salt.
  5. Confirm the OnePay API Base URL.
  6. Select the correct payment journal.
  7. Configure supported currencies and countries when required.
  8. Enable the payment provider.
  9. Add the callback URL to the OnePay merchant portal.

Callback URL

Configure the following public HTTPS endpoint in the OnePay merchant portal:

https://your-domain.com/payment/onepay/webhook

Important Notes

  • Test the integration with non-production credentials before going live.
  • The callback URL must be publicly accessible through HTTPS.
  • OnePay transaction limits and minimum amounts depend on the merchant account.
  • Configure the payment provider separately for each company when different credentials are used.
  • An invoice may temporarily display In Payment until the payment is reconciled according to the Odoo accounting configuration.
  • This module does not include a OnePay merchant account, transaction fees, or merchant onboarding.
